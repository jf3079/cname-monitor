CNAME Monitor

Tracks CNAME records for your domains and flags changes. Background checks run on a schedule; this page shows the latest results and lets you manage the domain list.

On load, this page pulls domains.json / settings.json straight from github.com/jf3079/cname-monitor (read-only, no login needed since it's public). To make the controls below actually save, paste a GitHub token above (a classic token with the repo scope, or a fine-grained token with Contents: Read and write on this one repo) — adding, editing, or removing a domain, or changing the interval / email alerts, will then commit straight to domains.json / settings.json / history.json on the main branch. The token stays only in this browser tab's memory — it's never written to disk, never sent anywhere but directly to api.github.com, and disappears the moment you reload the page or click "Clear". Without a token, those controls just preview the change here; use "Edit config on GitHub" to change things there instead.
