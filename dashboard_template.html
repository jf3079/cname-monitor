CNAME Monitor

Tracks CNAME records for your domains and flags changes. Background checks run on a schedule; this page shows the latest results and lets you manage the domain list.
Config not connected
"Connect config folder" lets this page read and save domains.json / history.json directly (select the cname-monitor folder). Works in Chrome/Edge. Without it, this page just shows a snapshot from the last scheduled run — added domains won't be saved to disk.
Check frequency
Saved to settings.json. The scheduled check reads this file each run and updates its own schedule to match, so a change here takes effect starting with the next run (up to one run at the old frequency after saving).
Email alerts
Requires a Gmail connector connected to Claude. Saved to settings.json; the scheduled check reads it each run and, if enabled, emails this address (in addition to the chat notification) whenever a monitored CNAME changes or stops resolving. You can leave this address blank for now and fill it in later.
