CNAME Monitor

Tracks CNAME records for your domains and flags changes. Background checks run on a schedule; this page shows the latest results and lets you manage the domain list.
Loading config from GitHub…
On load, this page pulls domains.json / settings.json straight from github.com/jf3079/cname-monitor (read-only, no login needed since it's public) — so this view stays current with whatever's committed there, even on a hosted copy of this page. To actually change the domain list or settings, click "Edit config on GitHub" and edit domains.json / settings.json there (GitHub's own editor, or clone and push) — this page and the next scheduled check will pick up the change automatically once it's on the main branch. The controls below can add/edit/remove rows for a quick local preview, but nothing here saves back to GitHub for you.
Check frequency
